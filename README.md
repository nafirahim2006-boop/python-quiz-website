# Python Quiz Website

## About the Project

This is a Python-based quiz application that allows users to answer questions and view their scores.

## Features

* Multiple quiz questions
* Answer validation
* Automatic score calculation
* Database integration
* Score storage

## Technologies Used

* Python
* SQL
* Database Management

## Project Files

* `quiz.py` – Main quiz program
* `database.py` – Database operations
* `quiz.sql` – SQL queries and database structure
* `score.txt` – Score storage
